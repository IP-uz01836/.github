<h2>一、先认清手里是哪种凭证</h2>
<p>住宅IP到手通常有三种形态：账号密码、IP白名单、带认证的网关地址。先看清服务商给的是哪一种，后面的填写才不会白做。</p>
<p>账号密码型要在代理设置里同时填用户名和密码，少一项就认证失败，报错往往只显示无法连接。</p>
<p>白名单型需要先把本地出口IP报给服务商加白，本地不填账号，换网络后要重新报备。</p>
<h3>账号密码型最常见</h3>
<p>网关型把认证放在服务端，本地只填地址和端口，账号在网页后台绑定设备，适合多人共用一条线路。</p>
<h2>二、Windows系统代理的入口在哪</h2>
<p>Win10和Win11都在设置里找网络和Internet，点进代理，打开使用代理服务器，填地址和端口后保存。</p>
<p>命令行可以用netsh winhttp设置，但它只管系统级HTTP请求，浏览器和部分软件不认，容易误判成没生效。</p>
<p>改完注销一次再登录，让新的系统代理彻底加载，老版本系统对这一步比较敏感。</p>

<h2>三、浏览器代理和系统代理不是一回事</h2>
<p>Chrome和Edge默认跟随系统代理，Firefox有独立设置页，可以在里面单独指定地址和端口。</p>
<p>只想让某一个浏览器走美国IP，用独立配置文件的插件更省事，不必去动全局设置。</p>
<p>需要桌面软件整体走代理时，系统代理或者客户端全局模式才是对的选择，两者别叠着开。</p>
<h3>两层同时开会打架</h3>
<p>系统代理和插件代理同时启用会形成嵌套，出口地址反而变得不可控，排查时先把其中一层关掉。</p>
<h2>四、认证信息填在哪里</h2>
<p>账号密码型在Windows弹窗里输入，首次连接会提示，勾选记住凭据就不必反复填。</p>
<p>Chrome复用系统凭据，Firefox要单独输入一次，同一个密码在两个浏览器里表现可能不同。</p>
<p>密码含特殊符号时注意输入法别切成全角，这是很常见又很难自己发现的低级错误。</p>
<h2>五、连上之后要验证的几件事</h2>
<p>先开一个IP查询页看出口是不是美国地址，再看DNS解析是否也走代理侧，两项都要看。</p>
<h3>看行为比看地址准</h3>
<p>接着登录目标站点一次，观察是否频繁弹验证码、是否提示异地登录，这比查地址更实用。</p>
<p>最后看延迟是否平稳，忽高忽低多半是线路拥塞，不是本地参数写错。</p>

<h2>六、连不上时的排查顺序</h2>
<p>先关掉代理确认本地能上网，再确认服务是否到期、是否超出并发数，这两项最容易被忽略。</p>
<p>然后核对地址、端口、认证方式、协议类型四项，绝大多数故障就出在这四项里。</p>
<p>仍然不通就看客户端日志，错误码比页面提示更直接，拿日志去问服务商也更快。</p>
<h2>常见问答</h2>
<h3>设置完浏览器打不开网页是怎么回事？</h3>
<p>答：多数是地址或端口写错，也可能本地网络本身不通。先关代理确认能上网，再逐项核对地址、端口和认证方式。</p>
<h3>系统代理和浏览器插件要同时开吗？</h3>
<p>答：不建议。两层叠加会造成嵌套，出口地址反而不对。固定用一层，另一层保持关闭。</p>
<h3>同一个IP能同时给几台电脑用？</h3>
<p>答：取决于套餐的并发数，常见是一到三个。多台同用会互相影响出口，账号之间的关联风险也会上升。</p>
<h3>设置好之后地址还会变吗？</h3>
<p>答：静态指租期内地址不变，退租或换套餐才会变。重启电脑、换路由器都不影响这个地址。</p>
